GAME FEATURES

Built for Bangladesh Railway

বাংলাদেশের রেলওয়ের পরিবেশকে কেন্দ্র করে একটি immersive mobile simulation experience তৈরি করার লক্ষ্য।

🚆

Realistic Trains

বাংলাদেশি ট্রেনের inspired ডিজাইন এবং বিভিন্ন train experience।

📍

Railway Routes

বিভিন্ন রুট, শহর এবং স্টেশনের game world।

🌧️

Dynamic Weather

বৃষ্টি, কুয়াশা এবং বিভিন্ন আবহাওয়ার পরিবেশ।

🌙

Day & Night

🚦

Railway Signals

railway signals এবং simulation gameplay mechanics।

Mobile First

ABOUT RAHAMĀT STUDIO

Building games from Bangladesh.

Rahamāt Studio একটি independent game development studio। আমাদের লক্ষ্য হলো বাংলাদেশকে কেন্দ্র করে original এবং memorable gaming experience তৈরি করা। Train Simulator Bangladesh আমাদের game development journey-এর একটি গুরুত্বপূর্ণ project।
